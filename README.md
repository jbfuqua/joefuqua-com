# joefuqua-com

Static site source for `joefuqua.com`.

## Commands

- `npm run build` copies the site into `dist/`
- `npm run clean` removes `dist/`
- `npm run start` serves the current directory at `http://localhost:3000`

## Structure

- `index.html` is the site source
- `scripts/build.mjs` creates the production output
- `scripts/serve.mjs` runs a local preview server
